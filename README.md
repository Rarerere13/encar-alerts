# Бот новых объявлений encar.com → Telegram

Проверяет encar.com каждые 10 минут по твоему фильтру и присылает новые
объявления в Telegram. Работает бесплатно на GitHub Actions — не нужен
сервер, не нужно ничего держать включённым.

## Шаг 1. Создать Telegram-бота

1. В Telegram напиши **@BotFather** → команда `/newbot`.
2. Задай имя и username бота (username должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — сохрани его, это `TELEGRAM_TOKEN`.

## Шаг 2. Узнать свой chat_id

1. Напиши своему новому боту любое сообщение (например "привет").
2. Открой в браузере:
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
3. В ответе (JSON) найди `"chat":{"id":123456789,...}` — это число и есть
   `TELEGRAM_CHAT_ID`.

Если ответ пустой — напиши боту сообщение ещё раз и обнови страницу.

## Шаг 3. Получить ссылку на API encar.com с твоим фильтром

Это единственный технически нетривиальный шаг, но он делается один раз.

1. Открой encar.com в **Chrome**, включи фильтры (марка, цена, год, пробег и т.д.),
   какие тебе нужны, нажми "Показать результаты".
2. Нажми `F12` (или правой кнопкой → "Просмотреть код") → вкладка **Network**.
3. В строке фильтра запросов введи `api.encar.com` — обнови страницу поиска
   (F5) или ещё раз примени фильтр.
4. В списке запросов появится один вида `list/premium` или `list/general`.
   Кликни по нему → справа вкладка **Headers** → скопируй значение
   **Request URL** целиком (это длинная ссылка, начинается с
   `https://api.encar.com/search/car/list/...`).
5. Пришли эту ссылку мне (или сам вставь её как секрет `ENCAR_API_URL` — см.
   шаг 5). Если структура ответа окажется нестандартной, в `bot.py` есть
   комментарий с подсказкой, что поправить.

## Шаг 4. Выложить код на GitHub

1. Зарегистрируйся на github.com, если ещё нет аккаунта.
2. Создай новый **публичный** репозиторий (например `encar-alerts`).
   Публичный — потому что тогда лимит бесплатных минут GitHub Actions
   не ограничен (для приватных репозиториев есть месячный лимит).
3. Залей в него все файлы из этой папки, сохранив структуру:
   ```
   encar-alerts/
   ├── bot.py
   ├── requirements.txt
   └── .github/
       └── workflows/
           └── check_encar.yml
   ```
   Проще всего — через веб-интерфейс GitHub: "Add file" → "Upload files",
   перетащить всё (включая папку `.github`).

## Шаг 5. Добавить секреты

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
Добавь три секрета:

| Имя секрета        | Значение                                   |
|---------------------|---------------------------------------------|
| `TELEGRAM_TOKEN`    | токен из шага 1                             |
| `TELEGRAM_CHAT_ID`  | число из шага 2                             |
| `ENCAR_API_URL`     | ссылка из шага 3                            |

Секреты не видны никому, кроме тебя, даже в публичном репозитории.

## Шаг 6. Запустить и проверить

1. Вкладка **Actions** в репозитории → workflow "Encar new listings check" →
   **Run workflow** (кнопка справа) — запустит бота вручную, не дожидаясь
   расписания.
2. Открой запуск → шаг "Run bot" → посмотри логи. Если всё ок, увидишь
   что-то вроде `Fetched 42 listings from encar` и
   `First run — saving 42 listings as baseline`.
3. Дальше бот будет запускаться сам каждые 10 минут и присылать в Telegram
   только НОВЫЕ объявления, появившиеся после первого запуска.

## Если что-то не работает

- **В логах "Fetched 0 listings"** — значит структура ответа encar другая.
  В файле `bot.py`, в функции `fetch_listings()`, замени строку
  `data.get("SearchResults", [])` — временно поставь
  `print(str(data)[:1500])` перед ней и посмотри в логах Actions, как
  реально называется список объявлений в JSON.
- **Telegram не присылает сообщения** — проверь, что писал боту первым
  (Telegram не разрешает ботам писать первыми, пока пользователь сам не
  начал диалог), и что `TELEGRAM_CHAT_ID` скопирован без кавычек и пробелов.
- **Ссылка из шага 3 быстро перестаёт работать** — encar иногда встраивает
  в запрос временный токен сессии. Если бот через несколько дней перестанет
  получать данные (404/403 в логах) — повтори шаг 3 и обнови секрет
  `ENCAR_API_URL`.
